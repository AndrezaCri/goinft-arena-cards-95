
# GoINFT - Digital Football Card Collection

Web3 platform for collecting, trading, and managing digital football cards as NFTs on the Chiliz Chain.

## Project info

**Live Preview**: https://dfba4067-dfe7-4793-8d1a-713025cb0f75.lovableproject.com

## Features

- Digital football card collection powered by NFTs
- Album completion system
- Card trading marketplace
- Pack opening experience
- Built on Chiliz Chain

## Technologies

- React with TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Web3 wallet integration

## Getting Started

Follow these steps to run the project locally:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to project directory
cd goinft

# Step 3: Install dependencies
npm install

# Step 4: Start development server
npm run dev
```

## Deployment

Simply open your project in [Lovable](https://lovable.dev) and click on Share -> Publish.
